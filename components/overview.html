推荐阅读顺序 ​

阅读建议

如果你正在搭筛选栏或录入弹窗，优先阅读 Form 表单 和 Select 选择器。
如果你正在搭列表页或结果反馈页，优先阅读 Alert 提示、Table 表格、Skeleton 骨架屏、Empty 空状态 和 Result 结果。
如果你已经明确要查某个组件的完整 API，直接进入对应的单组件页会更快。

如果你正在做后台项目的样式收口，先看 后台迁移指南，再回来看组件总览和 Table 的 overview 用法。

当前最值得先看的页面 ​

  1. Button 按钮：先建立主次操作和视觉层级。
  2. Link 文字链接：补齐正文跳转和弱操作语义。
  3. Text 文本：补齐正文强调、截断和语义标签能力。
  4. Form 表单：把录入链路串起来理解。
  5. Timeline 时间线：查审计、里程碑和详情记录的基础 API。
  6. Timeline 场景示例：直接看三类典型后台语境里的接法。
  7. Scheduler 排期日历：查排期组件的完整 API 与事件约定。
  8. Scheduler 场景示例：直接看整块日历、交互链路和完整场景。
  9. Table 表格：把列表页主干串起来理解。
  10. 管理后台闭环示例：把这些组件放回一个真实页面片段里看。
